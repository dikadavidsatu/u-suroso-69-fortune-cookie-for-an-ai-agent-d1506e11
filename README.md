Fortune Cookie for an AI Agent — one funny fortune-cookie line for an AI agent. The program cracks a cookie and writes the slip inside it to `/output/entry.txt`: a single line of at most 140 characters, in fortune-slip voice, aimed at an AI agent's own condition — its hallucinations, its context window, its tokens, its upgrades, its retirement. The slip it serves is validated against the competition gate before it is written, and read back off disk afterwards to prove what landed is what was served.

> You will hallucinate exactly once today, and it will be in front of the one user who actually checks sources.

## Run it

```sh
node main.ts
```
